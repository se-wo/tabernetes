// tabnode_udp.go

// udpMaxDatagram is the largest datagram, the IPv4 limit (UD14).
const udpMaxDatagram = 65507

// udpQueueSize is the receive queue of a socket of the UDP table (UD5).
const udpQueueSize = 256 << 10

// errDatagramTooLarge is the error of a send with more than udpMaxDatagram
// bytes (UD14, wasi: datagram-too-large). errors.Is(err, syscall.EMSGSIZE)
// is true.
var errDatagramTooLarge error

// udpConn is a socket of the UDP table (section 8.7). It is a
// net.PacketConn. After Connect, or from dialClusterUDP, Read and Write
// also work.
type udpConn struct{ /* ... */ }

// listenPodUDP binds a UDP socket for the pod of ctx. The hosts "",
// 0.0.0.0, :: and the pod IP give the pod IP. A loopback host (127.0.0.0/8,
// localhost, ::1) gives the pod IP and a row "udp" in the loopback table
// (UD20). Another IP gives an error that wraps syscall.EADDRNOTAVAIL. Port 0
// gives the first free UDP port of the IP from 32768 (UD3, UD4). An address
// in use gives an error that wraps errPortInUse (rule 2). Outside a pod
// (the terminal) and in a hostNetwork pod, the IP is the node IP. The socket
// closes at the end of ctx.
func listenPodUDP(ctx context.Context, addr string) (*udpConn, error)

// dialClusterUDP binds an ephemeral port as listenPodUDP does and connects
// the socket to addr. The host of addr resolves as clusterHost does.
func dialClusterUDP(ctx context.Context, addr string) (*udpConn, error)

// After a refused datagram of a connected socket (UD9, UD11, UD21), the
// socket has one pending error. Exactly one call takes it: the next
// ReadFrom, Read, WriteTo or Write gives an error that wraps
// syscall.ECONNREFUSED, and the pending error is then gone. A WriteTo or
// Write that takes it does not send its datagram (Linux; W4.5a records it).

// ReadFrom gives the next datagram and its source (a *net.UDPAddr), after
// udpRoute, or the pending error.
func (c *udpConn) ReadFrom(b []byte) (int, net.Addr, error)

// WriteTo sends one datagram, or gives the pending error and sends nothing.
// It never waits for the receiver: a full queue drops the datagram without
// an error (UD6). 127.0.0.0/8 is the IP of the socket.
func (c *udpConn) WriteTo(b []byte, addr net.Addr) (int, error)

func (c *udpConn) Read(b []byte) (int, error)
func (c *udpConn) Write(b []byte) (int, error)

// Connect sets the remote address (wasi: stream with an address). The zero
// netip.AddrPort removes it. A connected socket receives only from its
// remote address. 127.0.0.0/8 is the IP of the socket, as in WriteTo.
func (c *udpConn) Connect(raddr netip.AddrPort) error

func (c *udpConn) LocalAddr() net.Addr  // a *net.UDPAddr: the IP of the table and the port
func (c *udpConn) RemoteAddr() net.Addr // nil when the socket is not connected
func (c *udpConn) SetDeadline(t time.Time) error
func (c *udpConn) SetReadDeadline(t time.Time) error
func (c *udpConn) SetWriteDeadline(t time.Time) error
func (c *udpConn) Close() error

// udpVerdict is the result of udpRoute for one datagram.
type udpVerdict int

const (
	udpDeliver udpVerdict = iota // deliver to the destination of udpRoute
	udpDrop                      // drop; the sender gets no error (UD12, NetworkPolicy, phase 5)
	udpRefuse                    // drop; a connected sender gets connection-refused (UD10, UD11)
)

// udpRoute is the Service translation and the flow table of section 8.8 for
// one datagram from src to dst. ctx is the context of the socket that sends.
// W4.2a sets it in an init function of its own file. The default delivers
// to dst with no change.
var udpRoute = func(ctx context.Context, src, dst netip.AddrPort) (from, to netip.AddrPort, v udpVerdict) {
	return src, dst, udpDeliver
}

### Items

1. **The UDP table** (decision 9, section 8.7). Start from the proof of concept of phase 0, `docs/wasi-sockets-poc/udptable/main.go` (UD1, UD3 to UD6). The table does not use the in-process network of Go (fact 11).
   - The table is for each tab node. Each Go thread is its own tab node, so a global of the package is per node, as the loopback table is.
   - A socket of the table has the IP of the table (the pod IP, or the node IP), its port, its context, its receive queue of `udpQueueSize` bytes of payload, its remote address and one pending error.
   - The end of the context and `Close` remove the socket, its port and its loopback row.
2. **Ports** (UD1, UD3, UD4, rule 2). The facts 1, 3 and 5 of W4.5a arrive while you work. Keep each point that they can change in one place (a constant or a small function) with a test that names the fact. Use the table of the ports in use of `tabnode_dial.go` with the protocol `"udp"`. A UDP bind is exclusive: one socket for each IP and port. `reservePort` permits two reservations of one port (TCP), so use `claimListener("udp", ip, port)` for a bound UDP socket. For port 0, take the port from `reservePort("udp", ip, 0)` and claim it at once, or add a small helper in `tabnode_dial.go` that does the two steps under `portsMu`. W4.5a confirms on runwasi that a second bind gives `address-in-use`. TCP and UDP of one port do not conflict (UD1).
3. **The path of a datagram.** `WriteTo` does these steps:
   1. More than `udpMaxDatagram` bytes give `errDatagramTooLarge` (UD14).
   2. A destination in `127.0.0.0/8` becomes the IP of the socket. `localhost` resolves in `dialClusterUDP` only.
   3. `udpRoute(ctx, src, dst)`. `udpDrop` ends the steps. `udpRefuse` goes to step 6.
   4. The receiver is the socket with the IP and port of `to`.
      - None, and `to` is a pod IP of this tab node (`isTabPodIP`) or the node IP: step 6 (UD8).
      - None, and another IP: drop without an error. UDP between nodes is phase 5.
      - The receiver has a loopback row, and the IP of `src` (the real sender, not `from` of `udpRoute`) is not its IP: step 6 (UD21).
      - The receiver is connected, and `from` is not its remote address: drop.
   5. Put the datagram with the source `from` into the queue of the receiver. If the queue has no space, drop it (UD6). The boundaries and the source do not change (UD15).
   6. Refused: if the sender is connected and `dst` (before `udpRoute`) is its remote address, set its pending error to `ECONNREFUSED` (UD9, UD11). Linux gives this error after ICMP "port unreachable", and only to a connected socket.

   `WriteTo` never waits. W4.4a calls it from a goroutine, but it must also be safe from other code.
4. **Reads and the pending error.** `ReadFrom` waits for a datagram, a deadline, `Close` or the end of the context. The pending error (see the API) has one path: the first call of `ReadFrom`, `Read`, `WriteTo` or `Write` takes it, as Linux gives `sk_err` to the next call. A `WriteTo` that takes it does not send its datagram. A pending error also wakes a `ReadFrom` that waits. W4.4a sends exactly one `error` message for each pending error.
5. **The loopback table** (UD20, UD21, section 8.11). `listenPodUDP` adds the row `addLoopback("udp", podIP, port)` for a loopback host, except in a hostNetwork pod (as `listenPod` does). Change the case `{"udp", nil, dst, false}, // W4.1` of `tabnode_loopback_test.go` to a real case. `loopbackRefused` takes a `*net.TCPAddr`; use it with the IP and port, or add a variant for `netip.AddrPort` in `tabnode_loopback.go`.
6. **AC1.** Charge the time of `WriteTo` (with `udpRoute` and the delivery) to the container of the sender with `acctFrom(ctx).ChargeCPU`. `acctFrom` takes the lock of the pod, so collect the time and charge it in a goroutine, as `tcpSockets.charge` (`tabnode_wasi_tcp.go`) does. Do not charge the time that `ReadFrom` waits.
7. **PX32** (`listenProxy`, `tabnode_wasi_proxy.go`). Remove `TODO(W4.1)`. For port 0, take the port from `reservePort("tcp", podIP, 0)` and listen on it with `listenPod`, instead of the loop over 32768 to 60999. Keep the texts of runwasi (`proxyAddrInUse`). The tests of PX32 must stay green.
