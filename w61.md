### Now on main

`pingCmd` (`coreutils_misc.go`, line 987) knocks with TCP on port 80: a connection or a refusal from a host that exists (`hostExists`) counts as a reply. A ClusterIP never answers. So today `ping` to a pod on another node gets replies (the TCP knock crosses the pod channel). `README.md` says "`ping` and `telnet` dial from the pod IP" (lines 73 to 76) and "`ping` has no ICMP: a TCP connection to the host stands in for it" (line 883).

### Items

1. **The decision** (IC4, IC5, fact 15). Add `func (p *netPolicy) allowedICMP(ctx context.Context, src, dst net.IP) bool` next to `allowedUDP`. It calls `decide` with no protocol (`""`) and the ports 0. The engine examines the egress of the source and the ingress of the destination in one call. It returns true without the engine only for a source in 127.0.0.0/8, a source that is the node IP, and `src == dst`. Until the informers sync, it allows.
2. **`ping`.** Keep the options and the output format. One decision for each echo request (IC8: the tab node examines each echo request). The source is the pod IP of the pod of `ctx` (`procOf(ctx)`), or the node IP for the terminal and `hostNetwork` pods:
   - a pod IP of a running pod on this tab node (`theTabNode.isTabPodIP(ip)`, not `podByIP`): a reply if `allowedICMP(src, dst)` allows it (IC1);
   - the node IP of this tab node: a reply if `allowedICMP(src, nodeIP)` allows it (IC2; the terminal and `hostNetwork` pods are exempt by their source);
   - 127.0.0.0/8 and the own pod IP: a reply;
   - a ClusterIP: no reply (IC6);
   - an IP in the pod CIDR of another node, or the node IP of another node (`nodeOf`, `nodeOwns`): no reply, and a line that ICMP between nodes is not available (IC3). Proposed: "ping: <ip> is on node <name>: ICMP between nodes is not available", then exit 1 at once. Decide the text and write it into 7.9;
   - another IP: no reply, as now for an address that nobody has.
3. **IC7, IC8: `README.md`, phase 6.** Two texts: a policy rule with `ports` does not match ICMP; a tab node examines each echo request, a Docker node only the first one of an ICMP flow (fact 15).
