### Items

1. **A channel of messages.** `dcConn` is a stream of bytes, so make a small type for the `udp` channel. `onmessage` copies one message (`js.CopyBytesToGo`) into the queue of channel rule 10 (at most 1,048,576 bytes; a full queue drops) and returns. One goroutine for each channel takes the messages and does the work. `send` gives one `Uint8Array` and never waits:
   - before each send, `readyState` must be `open`, else drop (a data channel can still be `connecting`, a leaving node is `closing`);
   - `js.Value.Call("send", ...)` panics when JavaScript throws (`portChannel.send` throws "channel closed"). Catch the panic with `defer recover()` and count it as a drop. A panic there stops the control plane.
2. **The header** (ND4, ND5, channel rules 2 and 3). An encoder and a parser of the 14 bytes. The parser does the examination of rule 3 and ignores bytes 6 to 13 of a credit. Count the drops for each reason and write a log line at most each 10 seconds.
3. **The node of an IP.** One helper, for example `udpLinkNodeOf(ip netip.Addr) string`: the node whose pod CIDR contains the IP, else the node whose `InternalIP` is the IP (channel rules 4 and 5). `nodeOf` lists all nodes and parses each CIDR for each call: keep a parsed table and build it again on node events, or at most one time each second.
4. **The page** (channel rules 1 and 4). `attachChannel` with the label `udp`:
   - without a node name (`from == ""`): close it;
   - from a Docker node, read `ordered` and `maxRetransmits`; close it with a log line if they are not `false` and `0` (ND3);
   - a second `udp` channel of the same node replaces the first one; the credit count starts at 0 (rule 8). Forget the channel when it closes or at `forgetNode`;
   - each datagram: the source must be the node IP or in a pod CIDR of the node (`nodeOwns`, ND7, ND8). The destination node comes from item 3. Your node (`tabNodeName`): call `udpFromNode`. Another node with a `udp` channel: send it there. Else, or the same node: drop.
5. **`udpToNode` on the page.** For a datagram of the UDP table of the page: item 3 gives the node; send to its channel. Else drop and return false. Drop an address that is not IPv4.
6. **The node worker** (ND2, ND20). It opens `udp` with `tabernetesOpen("udp")` after its tab node started. `udpToNode` sends each datagram with a destination of another node (item 3) to the page. A datagram from the page goes to `udpFromNode`. The goroutine of item 1 counts each message for the credit when it took it, also when it dropped it, and sends credits as rule 8 says (before 64 KiB, at most 50 ms).
7. **Credits on the page** (ND11). For each node worker channel, count the bytes of the messages that the page sent and subtract the credits. Drop a message when the count plus the message is more than 1,048,576 bytes.
8. **`bufferedAmount`** (ND12, page part). Before each send to a Docker node, read `bufferedAmount`. Above 1,048,576 bytes, drop.
9. **CPU time.** The page relays datagrams between other nodes. This is work of the control plane: do not charge it to a pod. Name it in the pull request.
